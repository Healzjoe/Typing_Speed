# Typing Speed Test

A desktop app built with Python and Tkinter that measures
how many words per minute you can type.

## Features
- Three difficulty levels: Easy, Hard, Very Hard
- Choose 30, 60 or 120 second tests
- Timer starts on your first keystroke
- Words per minute and correct-word count
- Best score saved separately for each level and time
- Right and wrong words highlighted in green and red

## How to run
python main.py

## Built with
Python 3, Tkinter
